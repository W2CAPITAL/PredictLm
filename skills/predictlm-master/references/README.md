# PredictLM Master portable references

These files exist so the sovereign skill can be exported/installed as one folder without losing the contracts it depends on.

Canonical sources remain elsewhere in the repository. Portable copies are not independent authorities.

## Files

- AGENT-FABRIC.md — bounded multi-agent orchestration and review.
- CONNECTOME_SOURCES.md — FlyWire/H01 provenance and biological limits.
- DATAJUD-NEURAL-MESH.md — operational truth for legal sources, local runtime, WebGPU and provider availability.
- NEUROCORE-CORES.md — Digital Brain/Cognitive cores contract snapshot.
- RELATORIOS-DOSSIES.md — Report Architect portable contract.
- RUNTIME-FEDERATION.md — local/browser runtime compatibility reference.

## Synchronization rule

CURRENT CODE → PREDICTLM MASTER → CANONICAL SPECIALIZED SKILL → PORTABLE REFERENCE.

Never let an old portable snapshot re-enable deprecated routing or override a newer runtime implementation.
