# Council X10

Cada lente recebe a mesma pergunta sem ler a primeira resposta das demais.

Formato por lente:
- verdict: pass/warn/fail/unknown
- facts
- assumptions
- risks
- recommendations
- tests/evidence needed
- confidence

FORGE: Product, Architecture, Builder, UX/Taste, Research/Domain.
AEGIS: Security/Abuse, Failure/QA, Legal/Privacy, Ops/Cost/Reliability, Devil's Advocate/Countercase.

Chair:
- decisão
- consenso
- divergências
- fatos
- suposições
- maior risco
- melhor oportunidade
- próximo passo
- teste de prova
- rollback
