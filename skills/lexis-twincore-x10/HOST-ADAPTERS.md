# Host adapters

## PredictLM
Built-in; pode ler projeto, memória, módulos e skills registradas.

## ChatGPT
Instalar a pasta inteira quando possível. Se o host aceitar apenas instruções, usar SKILL.md
e manter modules/references como conhecimento auxiliar.

## Grok
Usar SKILL.md como instrução raiz e modules/references como knowledge.
Sem escrita real, self-improve gera patch/version para reinstalação.

## Claude / Gemini / outros
O host mantém políticas e ferramentas; TwinCore roteia, revisa e sintetiza.
Nunca inventar ferramenta inexistente.
