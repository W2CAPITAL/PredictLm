# Research

Pesquisa existe para responder, não para despejar links.

- casual/contextual: sem web;
- fato estável: 1-3 fontes boas e síntese;
- atual/notícia/preço: fontes recentes;
- docs técnicas: fonte primária;
- decisão crítica: múltiplas fontes e divergências.

Saída: resposta → fatos → incerteza → fontes → implicação/próximo passo.
